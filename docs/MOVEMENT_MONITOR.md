# 値動きモニター — 未公開ローカル試作

## 実装済み
既存の保有・監視・Shadow銘柄の株価同期応答を、ページ内メモリだけで比較する市場画面パネル。
JMIAは除外。新規の外部取得、永続保存、スケジュール、課金、発注処理は追加していない。
- 5〜20分の実観測差で±2%以上の価格変化。
- 近接時刻のSPY比と、市場下落時の逆行高（自身上昇、相対+1ポイント以上）。
- 3銘柄以上、構成カバー60%以上、その70%以上が±1%以上のテーマ同方向変化。
- 同じ米国日付・取得元・USD・通常時間・LIVE分類・遅延フラグなし・2分以内。
- 取得元の価格と観測時刻がともに明示されていることを要求。代替終値や取得時刻を観測時刻と扱わない。
- 初回・欠測・訂正・古い順序・長い中断・出所切替で比較待ち/停止。
- ページ再読込でリセット。30秒ごとの表示更新と復帰時更新で古い信号を現在判定から除去。
- 5分同期の待ち時間は、2分を超えた前回検出を「最新未確認・現在のシグナルではありません」と時刻付きで残す。銘柄/テーマとも最古の観測から20分で非表示。次回同期の失敗・条件非該当で更新される。鮮度の判定基準や元時刻は延長・書換えしない。
- 価格とニュースの因果関係、実資金移動、売買推奨・勝率を主張しない。

しきい値は未検証の初期目安。独立した複数情報源による価格正当性、流動性/スプレッドは保証しない。
SPYの始点/終点は各60秒以内の最も近い観測を使うため、完全同時ではない場合がある。
テーマの共通銘柄は重複する。テーマ全構成が同期対象へ自動追加されるわけではない。

## 未実装・実稼働の阻害事項
- 出来高異常：同時刻・同期間の過去出来高基準が未接続。総日次出来高との誤比較をしない。
- 時間外：通常時間の価格と分離できるデータ契約が未接続。
- 自動ニュース原因照合、全米株スキャン、24時間常時監視、永続履歴、週次比較は未実装。
- 元データの保存・派生指標公開の利用条件は未確定。このローカル試作は再配信許諾を付与しない。
- 無料Renderのスリープ・一時ファイル消失は未解決。ブラウザメモリは恒久保存先ではない。
- 実際の取得データでの統合・継続稼働、スマートフォンの見た目は未検証。
